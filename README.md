# SHADOW PARK

SHADOW PARK is an in-progress mobile-first Decentraland World about asynchronous human presence. A visitor answers one daily question by walking left or right, then leaves a persistent lightweight Shadow for future visitors.

Current verified status: the ugly authoritative slice compiles, pure state tests pass, and local scene storage survives a full preview-server restart. Rendered movement, two-client observation, and real mobile testing remain open verification gates. See `docs/TECHNICAL-VERIFICATION.md` for the evidence ledger and `docs/BUILD-PLAN.md` for milestones.

No World, NAME, LAND, MANA, hosting, or paid assets have been purchased. Organizer-provided World collaborator access is an external deployment dependency.

This README is intentionally a status stub. It will be replaced through the `perfect-readme` workflow only after shipped behavior, screenshots, test counts, limitations, and a live World can be verified.
