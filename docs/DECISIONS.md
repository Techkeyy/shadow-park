# Decision Log

## 2026-08-24: organizer access replaces purchase

Do not buy a Decentraland NAME, LAND, MANA, World, hosting, assets, or any other product. Publishing remains an external dependency until the organizer grants World collaborator access.

## 2026-08-24: asynchronous presence is the competitive lane

The park is designed to be socially meaningful with zero concurrent visitors. Live multiplayer acknowledgement is a bonus, not the core.

## 2026-08-24: authoritative off-chain state, no custom contract

Use Decentraland authoritative scene state and Server Side Storage. A blockchain vote adds fees and friction without strengthening the product promise.

## 2026-08-24: pin the authoritative SDK by exact build

Pin `7.26.1-32239895147.commit-3c77d90`, resolved from the moving `auth-server` tag on 2026-08-24. Revisit only through a deliberate verified upgrade.

## 2026-08-24: guest participation without durable-history promise

Guests may vote. The server can use the current runtime identity to prevent duplicate voting in the active question, but cross-device/session permanence is not promised until proven.

## 2026-08-24: lightweight Shadows first

Use primitives/stylized silhouettes for the vertical slice and performance proof. Full avatars/NPCs are not load-bearing and will only be considered if mobile evidence supports them.
