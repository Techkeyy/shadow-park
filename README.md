# SHADOW PARK

SHADOW PARK is an in-progress mobile-first Decentraland World about asynchronous human presence. A visitor answers one daily question by walking left or right, then leaves a persistent lightweight Shadow for future visitors.

Current verified status: the authoritative slice compiles, pure state tests pass, local scene storage survives a full preview-server restart, and correlated mobile hydration passed at 807 ms request-to-render. Two-client observation remains open because no second first-party client is available; the Friendzone organizer has granted deployment access to `TheShire.dcl.eth`, but no deployment has been performed. See `docs/TECHNICAL-VERIFICATION.md` for the evidence ledger and `docs/BUILD-PLAN.md` for milestones.

No World, NAME, LAND, MANA, hosting, or paid assets have been purchased. `TheShire.dcl.eth` access is organizer-granted; deployment remains intentionally paused.
